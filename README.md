# SecLab

SecLab is a cybersecurity home lab for practicing Linux
administration, networking, service configuration, system troubleshooting, and
security workflows in a controlled environment.

## Environment

- macOS host
- UTM
- Linux server
- Laptop-based console and analysis tools

## Architecture

```text
Laptop
└── UTM
    └── Linux server
        ├── System administration
        ├── Service configuration
        ├── Network configuration
        └── Security experimentation
```

The Linux server and laptop-based tools provide the primary environment for
administration, networking, troubleshooting, and security practice.
